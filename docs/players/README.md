# Cosmic Crusade player guides

| Guide | For |
|---|---|
| [How to play](HOW-TO-PLAY.md) | Your first game in the app: the menu, the table, taking turns, reacting, tips. |
| [Rulebook](RULEBOOK.md) | The full rules: cards, races, rounds, Duels, Rank, and the Warzones, Archons and Spacecraft modules. |
| [Glossary](GLOSSARY.md) | Every term on the cards and in the app. |
| [Playing online](PLAYING-ONLINE.md) | Hosting and joining with a code, chat, what happens when someone drops. |
| [LAN guide](LAN-GUIDE.md) | Playing on your home network with the built-in LAN Server. |
| [Host your own server](HOST-YOUR-OWN-SERVER.md) | Setting up your own free online relay on Cloudflare, and handing out a build that uses it. |

These guides are installed with the game. Open them from the **"New to Cosmic Crusade?"** links on the main menu, or from **Start menu → Cosmic Crusade How to Play**.
