# Cosmic Crusade: Glossary

The words used on the cards, in the app and in the [Rulebook](RULEBOOK.md), in alphabetical order. A term in *italics* has its own entry.

| Term | Meaning |
|---|---|
| **Action** | An *Order* you issue on your turn. It takes effect, then goes to the *Issued pile*. |
| **Active Warzone** | *(Warzones)* The Warzone in play this round. It affects both players. |
| **Advance** | Move a Unit from a *Standby Node* into the empty *Unit Node* in front of it. It counts as a *Deploy*. |
| **Allied** | Controlled by the same player. |
| **Archon** | *(Archons module)* One of 12 ancient power cards in their own shared deck. It's also a race, which is *neutral*. |
| **Archon draw** | *(Archons)* Once per game, at *Start-up*: draw one card fewer, see 3 Archons and keep 1. You must play it that round. |
| **Assemble** | A Synthenoid keyword. On your turn, *retire* a card with Assemble from your hand to add its Rank to one of your Synthenoids in play. |
| **Base Rank** | A Unit's printed Rank, before any changes. Some effects set it to a new value. |
| **Brute** | A Unit *class*: Rank 4, no ability, Unit Nodes only. |
| **Bystander** | A Unit *class* (Visiting Diplomat). |
| **Champion** | A Unit *class* that can go on a Unit Node or the *Leader Node*. Usually boosts its race. |
| **Class** | A Unit's type: Leader, Champion, Brute, Minion, Underling, Bystander, or (Spacecraft) Craft. It decides where the Unit can go. |
| **Clean-up** | The last step of a *round*: Units on the battlefield are retired, Ongoing Orders go to the *Issued pile*, nodes unlock. |
| **Control / Controller** | You control the Units on your side of the board. If a Unit moves to the other side, control moves with it. |
| **Control line** | The middle of the board, between the two players' sides. |
| **Copy** | *(Mr Morph, Forced Mitosis, Androsiar)* A Unit that enters play as another Unit: printed Rank, class and ability, but not that Unit's current changes. |
| **Crew** | *(Spacecraft)* The Unit aboard a ship. It's *elevated* and adds its Rank to the ship's. |
| **Deck mode** | Standard (the card pool's copy counts), *True Singleton* or *Random Draw*. |
| **Deploy** | Announce a Unit going to a node: from your hand, by *advancing* from Standby, or from a pile when a card allows it. Your opponent can respond before it's *Played*. |
| **Draw** | Take cards from the decks. You choose the deck for each card. |
| **Duel** | Two Units compare Rank and the lower is *Nullified*. In a tie the *weakness* cycle decides, and if it doesn't, both are Nullified. |
| **Elevated** | *(Spacecraft)* A crew is in the air: ground effects aimed at "the Opposing Unit" meet its ship instead. |
| **Empty** | A node with no card that isn't *Locked*. |
| **End of Main Phase** | When both players have passed one after the other. End-of-Main effects happen, then the round is scored. |
| **First player** | Who takes the first turn of a round: the last round's winner, or at random in round 1. |
| **Hand** | Your cards: you keep 5 Units and 3 Orders at the start of each round. Hidden from your opponent unless an effect reveals it. |
| **Immune** | Unaffected by every effect and ability except its own, good or bad. Game rules still apply. |
| **In play** | On a Unit Node, *Leader Node* or *Order Node*. Standby is *not* in play. |
| **Issue** | Play an *Order* from your hand. Your opponent can respond before it takes effect. |
| **Issued pile** | Where Orders go once they're done, and where Nullified or Retired Orders go. |
| **Leader** | A Unit *class* that can only go on your *Leader Node*. Never goes into Standby. |
| **Leader Node** | Your one node for a Leader or a Champion. It counts towards your total and opposes the other Leader Node. |
| **Lock / Locked** | A Locked node can't be played to, and doesn't count as Empty. Any node, either side. Every node unlocks at *Clean-up*. |
| **Main Phase** | The middle of a round, when players take turns. |
| **Manipulate N** | Give any Unit in play, on either side, +N or −N Rank (your choice). It lasts while the Unit stays in play. |
| **Minion** | A Unit *class*: the core of most armies. |
| **Neutral** | Not part of the *weakness* cycle: Galactic Council, Archon and Neutral cards. |
| **No Leaders** | A game mode without Leaders, Leader Nodes or the cards that need them. |
| **Node** | A space on the board: Unit, Leader, Standby or Order Node. |
| **Nullify** | Destroy: a Unit goes to the *Nullified pile*, an Order to the *Issued pile*. |
| **Nullified pile** | The shared pile of destroyed Units. Necrolites raise their dead from it. |
| **Ongoing** | An *Order* that sits on an Order Node and keeps working until *Clean-up*. |
| **Opposed** | The node directly across the control line holds a card. |
| **Opposing Unit / Leader** | The Unit (or Leader) on the node directly across from this one. |
| **Order** | A card you issue for an effect: an *Action*, *React* or *Ongoing*. |
| **Order Node** | One of your two spaces for *Ongoing* Orders. |
| **Owner** | On cards, it means the *controller*. |
| **Pass** | Do nothing this turn. The Main Phase ends when both players pass one after the other. Passing isn't final. |
| **Played** | A Unit that survives any responses to its *Deploy* and enters its node. Its "When you play" ability fires. |
| **Rank** | A Unit's strength: its Base Rank plus every change. Can go below 0. |
| **React** | An *Order* you can issue whenever its condition happens, on either player's turn. Doesn't use your turn. |
| **Random Draw** | A deck mode: every draw is a random card of that type, and decks never run out. |
| **Retire** | Remove normally: a Unit goes to the *Retired pile*, an Order to the *Issued pile*. |
| **Retired pile** | The shared pile of Units removed normally, e.g. at the end of each round. |
| **Round** | Start-up → Main Phase → scoring → Clean-up. Win enough rounds to win the game. |
| **Rounds to win** | How many round wins win the game (default 3). |
| **Seed** | *(App)* A number that fixes the shuffle, so the same seed gives the same game. Blank means random. |
| **Ship / Spacecraft** | *(Spacecraft module)* A Unit that flies over a node and can carry a *crew*. |
| **Signature Action** | Each race's common Action, 5 copies in the Standard pool: Blasters at Dawn, Shallow Grave, Meditate, Adapt, Salvage for Parts. |
| **Stack** | *(App)* The list of cards waiting to resolve while players respond to each other. The last one added resolves first. |
| **Standby Node / Zone** | Three spaces behind your Unit Nodes where Units wait. Not *in play*. Standby Units stay through *Clean-up*. |
| **Start-up** | The first step of a round: draw up to 5 Units and 3 Orders, reveal a Warzone, decide the first player. |
| **Suppress** | The named abilities or effects are ignored. |
| **Tiebreak** | When the totals are equal, the player who wins more *opposed* node pairs wins the round. |
| **Token** | *(Spacecraft)* A card made by an effect (the Fighter). It vanishes whenever it leaves play. |
| **Total Rank** | The sum of the Ranks on your Unit Nodes and Leader Node. The higher total wins the round. |
| **True Singleton** | A deck mode with one copy of every card. |
| **Turn** | One player's go: exactly one action, or a pass. |
| **Underling** | A Unit *class*: cheap and tricky. |
| **Unit** | A card that fights on the board. |
| **Unit Node** | One of your three battlefield spaces, U1–U3. |
| **Warzone** | *(Warzones module)* A battlefield environment revealed each round that affects both players. |
| **Weakness** | The cycle that decides tied Duels: Space Cowboys ▶ Necrolites ▶ Overmind ▶ Blaarg ▶ Synthenoids ▶ Space Cowboys. |
| **When you play** | An ability that fires when the Unit is *Played*, but not if its Deploy was cancelled. |

## In the app
| Term | Meaning |
|---|---|
| **Pass (Space)** | Ends your turn without acting, or answers "no response" when you could React. |
| **Pause when I can React** | On: the game stops whenever one of your Reacts could answer. Off: it never stops for you. |
| **Glowing** | A card you can play, or a node or pile you can target. |
| **Room code** | *(Online)* The 5-letter code the host gives the other player so they can join. |
| **Server** | *(Online)* The address of the relay that connects the two players' games. |
| **LAN Server** | *(Online)* The small program that lets one PC host games on a home network. |
